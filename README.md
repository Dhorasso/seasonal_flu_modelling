# Time-varying transmission dynamics in seasonal influenza

Code accompanying the paper *"Bayesian inference for time-varying transmission in seasonal influenza: An application to Irish hospitalisation data."*


## Getting started

### 1. Clone the repository

Clone the GitHub repository to your local machine using Git:

```bash
git clone https://github.com/Dhorasso/seasonal_flu_modelling.git
```

Navigate into the project directory:

```bash
cd seasonal_flu_modelling
```

Alternatively, download the repository as a ZIP file from the [GitHub repository](https://github.com/Dhorasso/seasonal_flu_modelling) by clicking **Code → Download ZIP**.

### 2. Repository structure

```text
.
├── data/
│   ├── simulated/          # Cached synthetic datasets
│   └── real/               # Laboratory-confirmed inpatient cases in Ireland
│                            # (2022/2023–2025/2026)
├── figures/
│   ├── fig_real/           # Figures from the real-data analysis
│   └── fig_sim/            # Figures from the simulation study
├── scripts/                # Entry-point and plotting scripts
├── src/                    # Model and inference code
└── README.md
```

### 3. Install the required R package

PMMH requires the `BayesianTools` R package. Install it using:

```r
install.packages("BayesianTools")
```

## `scripts/` (entry points)

The following scripts run the analyses and generate plots.

| Script | Purpose | Data |
|---|---|---|
| `run_seihr_real_data.R` | Fits the SEIHR model to a single influenza season | Real data in `data/real/flu_seasons/` |
| `run_seihr_sim_data.R` | Fits the SEIHR model to simulated data | Synthetic data in `data/simulated/` |
| `plot_param_est.R` | Plots parameter posterior distributions and trace plots | Model inference results |
| `plot_traj_real.R` | Plots the time-varying transmission rate, effective reproduction number, and cases for four influenza seasons | Real-data analysis results |
| `plot_traj_sim.R` | Plots trajectories for three simulated scenarios | Simulation results |

## Methodology

The analysis uses a stochastic SEIHR epidemic model with a time-varying transmission rate represented as a Gaussian random walk.

Bayesian inference is performed using particle marginal Metropolis–Hastings (PMMH), incorporating a fixed-lag particle filter to estimate the latent epidemic states and infer model parameters.

The repository includes scripts for both real-data analyses of influenza hospitalisations in Ireland and simulation studies.

## Output figures

Figures generated by the analysis and plotting scripts are saved in:

- `figures/fig_real/` — Figures from the real-data analysis.
- `figures/fig_sim/` — Figures from the simulation study.
